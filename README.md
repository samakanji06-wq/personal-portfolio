My Personal Portfolio

A simple personal portfolio website built with HTML and CSS, showcasing who I am, what I do, and how to get in touch.

🔗 Live site: [samakanji06-wq]

About

This is my personal portfolio — a single-page site with a hero section, an about section, and a contact form. I built it as a hands-on way to practice HTML and CSS fundamentals: layout, responsive design, and styling from scratch.

Sections
Home — introduction and a photo
About Me — a short bio
Contact Me — a form to get in touch, plus direct links (email, WhatsApp, TikTok)
Built with
HTML5
CSS3 (Flexbox for layout)
Font Awesome for social icons
Formspree for handling form submissions
Structure
├── index.html
├── styles.css

└── README.md
Running locally

Clone the repo and open index.html in your browser — no build step or server required.

bash
git clone https://github.com/samakanji06-wq/portfolio.git
cd portfolio
